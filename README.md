# Factory — Next.js agency website

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Stack
- Next.js / React / TypeScript
- React Three Fiber + Three.js
- Drei
- Framer Motion
- CSS responsive layout

The hero contains a real-time Three.js factory/conveyor scene. Replace the placeholder portfolio visuals and contact email with real Factory assets before production.
